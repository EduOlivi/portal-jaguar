# Acampamento Jaguar · VI Campori DSA 2027

Simulação da área de acampamento do Clube de Desbravadores Jaguar (lote de esquina de 21 × 20 m, edição Ômega, setor AMC): portal de esquina em 3D, barracas por unidade com meninos e meninas separados, mapa ilustrado, planta técnica com tabela de marcação, plaquinhas das unidades, cozinha, materiais e orçamento.

Página única: abra `index.html` num servidor local (ex.: `python -m http.server`) ou pelo link publicado. Usa Three.js 0.147 via CDN.
